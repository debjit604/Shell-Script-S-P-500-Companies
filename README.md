
 S&P 500 Companies Sorter

Downloads S&P 500 constituent data from GitHub and sorts all companies by founding year (oldest to newest).

## Usage


chmod +x sp500_sort.sh
bash sp500_sort.sh
Output
sp500_companies_sorted_by_year.csv — Sorted CSV with columns: Company Name, Headquarters Location, Founded Year, Symbol, Sector

Terminal summary showing top 15 oldest and newest companies
